## 📌 스킬 개요 (Overview)

`/박개성컨설팅` 스킬은 단순 대화형 LLM의 환각(Hallucination)을 100% 통제하는 **신경기호학적(Neurosymbolic) 하이브리드 엔진**과 **예측형 의사결정 시뮬레이션(Predictive DSS Engine)**을 탑재하고 있습니다.

### 🏛️ 핵심 4-Part 보고서 출력 구조
1. **PART I. 박개성 경영 분석 프레임워크 가이드**:
   - 신경기호학적 4단계 파이프라인 (Neo4j Graph + LLM + T-SIRT 면역 검증)
   - 성과 수식 \(Y = f(\text{Mission}) \times \prod M_j \times \sum (T_i \cdot w_i) - \text{Friction}\) 및 R3 구매 20배 레버리지 수식
   - 박개성 4대 경영 공리 (R1: 선행타격, R2: 거버넌스 불변, R3: 20배 구매, R4: 4M 곱셈)
   - 12대 실행 테마 (T1 ~ T12) 및 5대 열매 100% 연결 Neo4j 온톨로지 지식 그래프
2. **PART II. 실증 케이스 분석 & 시각화 (본론)**:
   - Crisis Diagnosis Red Alert Hero Card & Before/After 4대 KPI 비교
   - 경영진 실행-영향력 4분면 매트릭스 (Action vs Impact Matrix)
   - 환자 여정 대기시간 병목 차트 & T6 구매 절감 재무 레버리지 차트
3. **PART III. 예측형 시뮬레이션 & Data-Based 미래 예측**:
   - **🎛️ 실시간 인터랙티브 DSS 시뮬레이터 위젯** (T6/T7/T2 슬라이더 조절 시 영업이익률, 순이익, 대기시간, 파산위험지수 실시간 연산)
   - 몬테카를로 1,000회 시뮬레이션 기반 3개년 영업이익률/순이익 예측 궤적 차트
4. **PART IV. 3단계 실행 로드맵 & 간트 파이프라인**:
   - Quick-Win (0~3M) ➔ Mid-Term (3~12M) ➔ Long-Term (12~24M+) 3대 실행 카드
   - 워크스트림별 간트 타임라인 프로그래스 바 테이블

## 💡 사용 방법 (How to Use)

### 1. Antigravity IDE 프롬프트에서 스킬 호출
Antigravity IDE 채팅창에 다음과 같이 입력합니다.

```text
/박개성컨설팅
```

### 2. 병원 데이터 및 고민사항 입력
AI가 데이터 입력을 요청하면, 아래와 같이 현재 병원의 상태나 고민을 입력합니다.

```text
- 병원 규모: 300병상 지방 종합병원
- 현재 상황: 최근 2년 연속 영업적자 (-4.2%), 환자 대기시간 58분, 이탈률 22.4%
- 고민 사항: 병원장이 50억 원대 신축 건물 건립 및 고가 장비 도입을 고려 중임
```

### 3. 자동 보고서 생성 및 웹 브라우저 기동
AGI 시스템이 무결성 검증을 거친 후, **카카오톡/이메일 전송에 완벽 호환되는 100% 단일 파일 인라인 HTML 보고서(`*_integrated.html`)**를 생성하고 자동으로 웹 브라우저를 실행합니다.
